# Security Governance Oversight

| Responsibility | Accountable owner | Frequency | Escalation |
|---|---|---|---|
| Critical patch compliance | CISO | Weekly | CEO after seven days overdue |
| Vulnerability remediation | Security Manager | Weekly | CISO for any critical exception |
| Network segmentation | Network Owner | Quarterly | Architecture Review Board |
| Database access review | Database Owner | Quarterly | CISO and Data Protection Officer |
| Monitoring coverage | Security Operations Lead | Monthly | Executive Risk Committee below 95% |
| Board security reporting | CEO | Quarterly | Board Security Committee |

Control evidence must identify the system, date, operator, test performed, result, and remediation owner. Risk acceptance above the approved threshold requires written Executive Risk Committee approval and a dated treatment plan.
